# Jai & Yogita — Wedding Invitation

A mobile-first wedding invitation for Jai and Yogita, designed around Jaipur architecture and the Mothya family celebration on Saturday, 21 November 2026.

## Run locally

```sh
npm install
npm run dev
```

Vite listens on the local network so the site can be previewed from a phone on the same Wi-Fi.

## Build for hosting

```sh
npm run build
```

Upload the contents of `dist/` to the hosting account's web root (for example, `public_html`). The site is configured for a root-domain deployment.

## Site contents

- Cinematic Hawa Mahal hero and invitation details
- The couple portraits and an interactive 3D rotating photo gallery
- A scroll-guided wedding-day timeline and venue directions
- Original decorative illustrations and locally stored image assets

Prototype pages, unused 3D experiments, extracted video frames, build output, and local preview exports are intentionally excluded from this repository.
